# Сократ — помощник педагога для диагностических работ

**Кейс SK01 · команда T004 Fazbear Entertainment, Inc.**: Калюжный А. О., Редняков Д. А., Звонарёв И. С.

«Сократ» — Telegram-бот для педагога. Он помогает составить диагностическую работу на 15–20 минут, выдаёт лист ученика и методичку в `.docx`, показывает связь заданий с выбранными планируемыми результатами из каталога источников. Второй сценарий разбирает типичную ошибку, описанную педагогом без имён детей, и предлагает проверочные вопросы и приёмы для следующего урока.

## Что уже работает

- Вход по паролю администратора или педагога, сессии с ограниченным сроком и блокировка перебора паролей.
- Создание работы: класс, предмет, тема, варианты, фокус УУД и число заданий; проверка запроса и показ предупреждений до генерации.
- Два Word-файла: ученический лист без ответов и методичка с решениями, картой результатов, временем, наблюдаемыми признаками и источниками.
- Анализ типичной ошибки с выдачей результата в чате и отдельного Word-файла.
- Отзывы по заданиям, перегенерация, разбор обезличенного ответа и ответа на вопрос рефлексии.
- Админ-панель: педагоги, статус и обновление нормативной базы, загрузка материалов школы, расходы.

Режим `USE_FAKES=true` использует демонстрационные данные кейса SK01 и не обращается к LLM. Он удобен для первого запуска. При `USE_FAKES=false` приложение подключает реальные модули по мере их появления; если модуль ещё не установлен, `app.py` пишет предупреждение и использует фейк.

## Первый сценарий для проверки

В боте нажмите «📝 Создать работу» и выберите **математика, 3 класс, умножение и деление, все три уровня, 4 задания**. Дождитесь двух `.docx`. Затем попробуйте «👍/👎 по заданиям» и «🔍 Анализ типичной ошибки». На ученическом листе уровни подписаны нейтрально: «Вариант А / Б / В».

## Подготовка

1. Создайте бота через [@BotFather](https://core.telegram.org/bots/tutorial): отправьте `/newbot`, следуйте подсказкам и сохраните выданный токен.
2. Скопируйте `.env.example` в `.env`. Заполните `TELEGRAM_BOT_TOKEN`, `ADMIN_PASSWORD` и `APP_SECRET`. Секрет можно создать командой `python -c "import secrets; print(secrets.token_urlsafe(48))"`. Файл `.env` не коммитится.
3. Для демонстрации установите `USE_FAKES=true`. Значения `LLM_PRICE_IN_PER_1M` и `LLM_PRICE_OUT_PER_1M` задайте числами, например `0` для режима фейков: пустые значения в `.env` не проходят проверку настроек.
4. Для реальной LLM создайте ключ на [странице ключей OpenRouter](https://openrouter.ai/settings/keys), укажите его в `LLM_API_KEY`, выберите `LLM_MODEL` и установите `USE_FAKES=false`. Инструкции OpenRouter по [подключению API](https://openrouter.ai/docs/quickstart). Никому не отправляйте токен бота или ключ API.

### Локальный запуск

Требуется Python 3.11 или новее; в CI используется Python 3.12.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
# Заполните .env по шагам выше.
python -m socrat.bot
```

Для Linux/macOS вместо активации PowerShell используйте `source .venv/bin/activate`, а вместо `Copy-Item` — `cp`. База SQLite создаётся при старте в `data/socrat.db`. Для входа отправьте боту `/start`, затем пароль администратора из `.env`. Педагогам пароли выдаёт администратор через админ-панель.

### Docker Compose

```bash
cp .env.example .env
# Заполните .env, включая USE_FAKES=true для демонстрации.
docker compose up --build -d
docker compose logs -f bot
```

Контейнер запускает `python -m socrat.bot`; каталог `./data` подключён как том для SQLite и материалов базы. Один и тот же токен Telegram-бота не следует использовать одновременно для локального процесса и контейнера с long polling. В `docker-compose.yml` приведён закомментированный пример сервиса Ollama для локальной модели.

## Стоимость и ограничения

Для заданной в примере модели `google/gemma-3-27b-it` на [странице OpenRouter](https://openrouter.ai/google/gemma-3-27b-it) на 24.09.2026 указано **$0.08 за 1 млн входных** и **$0.16 за 1 млн выходных токенов**. Укажите эти значения в `LLM_PRICE_IN_PER_1M` и `LLM_PRICE_OUT_PER_1M`, если выбрали эту модель. Цена зависит от модели и провайдера и может измениться; сверяйте страницу модели перед запуском. Оценка для 10 000 входных и 2 000 выходных токенов — $0.00112 за вызов, без дополнительных попыток генерации. Фактические расходы показывает админ-панель. Режим фейков не делает платных LLM-вызовов.

Система не заявляет полного покрытия ФГОС. Она показывает только результаты, присутствующие в каталоге, с источником, разделом и страницей; внутренние коды результатов не являются номерами пунктов ФГОС. Загруженные материалы школы используются как контекст и не считаются нормативными источниками. Время работы расчётное. Не вводите имена и другие данные детей; описание ошибки и ответ должны быть обезличены. Разбор ответа фиксирует наблюдаемые признаки, не ставит диагноз и не оценивает личность.
