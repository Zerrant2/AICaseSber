# Сократ — помощник педагога для диагностических работ (кейс SK01)

**Команда:** T004 Fazbear Entertainment, Inc. — Калюжный Артём Олегович, Редняков Дмитрий Алексеевич, Звонарёв Иван Сергеевич.

Telegram-бот, который:
- **собирает компактную диагностическую работу на 15–20 минут** по ФГОС для 1–11 классов. Уровни — лёгкий, базовый, сложный или все три; наблюдаемые УУД; рефлексия. Бот выдаёт два Word-файла: лист ученика без ответов и методичку учителя с картой планируемых результатов (источник, раздел, страница);
- **анализирует типичные ошибки класса** по описанию педагога. Раскладывает ошибку на операциональный, концептуальный, регулятивный и коммуникативный слои и предлагает приёмы коррекции. Данные детей не обрабатываются.

> README в разработке: финальную версию к сдаче готовит Codex (задача X9).
> Архитектура — [ARCHITECTURE.md](ARCHITECTURE.md). Правила для ИИ-агентов — [AGENTS.md](AGENTS.md).

## Быстрый старт (разработка)

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
cp .env.example .env        # заполнить TELEGRAM_BOT_TOKEN, ADMIN_PASSWORD, APP_SECRET, LLM_API_KEY
python scripts/build_fixtures.py
pytest -q -m "not llm and not network"
```
