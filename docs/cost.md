## Стоимость

| Сценарий | DeepSeek V4.1 Flash ($0.04 / $1.00) | Gemma 3 27B ($0.08 / $0.16), для сравнения |
|---|---|---|
| Одна работа (3 уровня × 4 задания) | **≈ $0.025–0.045** (замер: $0.0365) | ≈ $0.005–0.01 |
| Работа одного уровня | ≈ $0.01–0.015 | ≈ $0.002 |
| Замена одного задания | ≈ $0.005–0.01 | ≈ $0.001 |
| Анализ типичной ошибки | ≈ $0.002–0.005 | ≈ $0.001 |
| Замена чисел («замени 4 на 5») | $0 — пересчитывается кодом | $0 |
| 100 педагогов × 10 работ в месяц | **≈ $25–45 в месяц** | ≈ $5–10 в месяц |

Основная часть цены у DeepSeek — выходные токены.

**Как снизить цену и время:**
- `LLM_REASONING=off` или `low` в `.env` (только OpenRouter) — отключает или сокращает «размышления» у моделей, которые их поддерживают. Проверьте качество на своём прогоне.
- `LLM_MODEL` — другая модель одной строкой, код трогать не нужно.
- `LLM_MAX_REPAIRS=1` — меньше починок; тогда чаще будут предупреждения «просмотрите задание».

## Прочие расходы

- **Telegram Bot API** — бесплатно.
- **Эмбеддинги** — не используются: поиск по нормативной базе работает на BM25.
- **Хостинг** — любой сервер с Docker: 1 vCPU, 1–2 ГБ RAM, около 1 ГБ диска (база, SQLite).
- **Локальная модель на сервере заказчика** (Ollama / vLLM) — оплаты API нет, но нужен GPU. Для моделей класса Gemma 3 27B — от 24 ГБ видеопамяти в 4-битной квантизации.
