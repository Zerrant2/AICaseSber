## Модель по умолчанию

`google/gemma-3-27b-it` через OpenRouter. Цена на странице модели на 24.09.2026 (данные из README Codex): **$0.08 / 1M входных** и **$0.16 / 1M выходных** токенов. Цена зависит от провайдера и может меняться.

## Токены на одну работу (расчёт по промптам)

| Операция | Вызовов | Вход, ток. | Выход, ток. |
|---|---|---|---|
| Вариант (4 задания), на уровень | 1 | ~2 500 (системный промпт с каталогом результатов и 15 приёмами + чертёж) | ~3 000 |
| Починка по ошибкам проверок (в среднем) | 0–1 на уровень | ~2 000 | ~1 500 |
| **Работа «все три уровня»** | 3–6 | **~7 500–13 500** | **~9 000–13 500** |
| Анализ типичной ошибки | 1 | ~2 000 | ~1 200 |

## Стоимость

| Сценарий | Gemma 3 27B ($0.08/$0.16) |
|---|---|
| Одна работа (3 уровня × 4 задания) | **≈ $0.002–0.003** |
| Анализ ошибки | ≈ $0.0004 |
| 100 педагогов × 10 работ в месяц | ≈ $2–3 в месяц |

Прочее: Telegram Bot API — бесплатно; эмбеддинги — не обязательны (поиск работает на BM25); хостинг — любой сервер с Docker (1 vCPU, 1–2 ГБ RAM); при локальной модели на сервере заказчика расходов на API нет, но нужен GPU (для Gemma 3 27B — от 24 ГБ видеопамяти в 4-битной квантизации).
