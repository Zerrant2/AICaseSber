*24.09.2026 · Claude. Фактические расходы по каждой работе пишутся в `work.meta` и видны в админ-панели бота («💰 Расходы»). Если OpenRouter возвращает стоимость запроса (`usage.cost`), берётся она, а тарифы из `.env` используются только как запасной расчёт.*

## Модель команды

`deepseek/deepseek-v4.1-flash` через OpenRouter. Тариф на странице модели на 24.09.2026: **$0.04 за 1M входных** и **$1.00 за 1M выходных** токенов. У отдельных провайдеров OpenRouter цены бывают ниже.

```
LLM_PRICE_IN_PER_1M=0.04
LLM_PRICE_OUT_PER_1M=1
```

## Стоимость

| Сценарий | DeepSeek V4.1 Flash ($0.04 / $1.00) | Gemma 3 27B ($0.08 / $0.16), для сравнения |
|---|---|---|
| Одна работа (3 уровня × 4 задания) | **≈ $0.011–0.016** | ≈ $0.002–0.004 |
| Работа одного уровня | ≈ $0.004–0.006 | ≈ $0.001 |
| Анализ ошибки | ≈ $0.0016 | ≈ $0.0004 |
| 100 педагогов × 10 работ в месяц | **≈ $11–16 в месяц** | ≈ $2–4 в месяц |

Основная часть цены у DeepSeek — выходные токены. Если бюджет важнее качества формулировок, модель меняется одной строкой `LLM_MODEL` в `.env`, код трогать не нужно.

## Прочие расходы

- **Telegram Bot API** — бесплатно.
- **Эмбеддинги** — не используются: поиск по нормативной базе работает на BM25.
- **Хостинг** — любой сервер с Docker: 1 vCPU, 1–2 ГБ RAM, около 1 ГБ диска (база, SQLite).
- **Локальная модель на сервере заказчика** (Ollama / vLLM) — оплаты API нет, но нужен GPU. Для моделей класса Gemma 3 27B — от 24 ГБ видеопамяти в 4-битной квантизации.
