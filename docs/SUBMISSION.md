# Сдача проекта «Сократ» через GitVerse

Эти действия выполняет участник команды после слияния проверенных PR в `main`. Публикуйте только готовую ветку: в ней должны быть README, материалы демонстрации и результаты проверки.

## 1. Создать репозиторий

1. Войдите на [gitverse.ru](https://gitverse.ru/) и создайте **публичный** репозиторий для проекта. Не добавляйте при создании README, `.gitignore` или лицензию: история уже есть в Git.
2. Скопируйте HTTPS-адрес нового репозитория со страницы GitVerse. Адрес ниже — пример, замените его своим.

## 2. Проверить историю перед публикацией

В PowerShell из корня проекта выполните:

```powershell
git switch main
git pull --ff-only origin main
git status --short
git log --all --name-only --pretty=format: -- .env data/socrat.db data/knowledge/raw
$secretFound = [bool](git log -p --all | Select-String -Quiet -Pattern 's[k]-or-', 'TELEGRAM_BOT_TOKEN=\s*\d{8,10}:[A-Za-z0-9_-]{35,}')
"Подозрение на ключ или токен в истории: $secretFound"
```

`git status --short` должен быть пустым, команда `git log --all --name-only ...` не должна вывести пути, а `$secretFound` должен быть `False`. Проверка ищет непустой токен бота: строка `TELEGRAM_BOT_TOKEN=` без значения в `.env.example` допустима. Если что-либо найдено, остановите публикацию, перевыпустите затронутые секреты и разберите историю с командой. Не вставляйте найденные значения в переписку или issue.

## 3. Отправить `main` на GitVerse

```powershell
git remote add gitverse https://gitverse.ru/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git
git push -u gitverse main
```

Если remote `gitverse` уже существует, проверьте его командой `git remote -v` и используйте `git remote set-url gitverse <верный-HTTPS-адрес>` только при необходимости. При запросе авторизации используйте способ, который предлагает GitVerse; пароль или токен не сохраняйте в репозитории.

## 4. Проверить публичную ссылку

Откройте страницу репозитория GitVerse в приватном окне браузера без входа в аккаунт. Убедитесь, что доступны `main`, README и материалы демонстрации, а исходный код открывается без авторизации. Скопируйте адрес страницы репозитория, а не адрес клона с `.git`.
