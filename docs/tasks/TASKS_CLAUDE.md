## C1. LLM-клиент `llm/client.py` · ✅ сделано (ветка claude/core) · к 24.09, 09:00

`OpenAICompatibleClient(settings)`, реализует `LLMClient`:
- `AsyncOpenAI(base_url, api_key, timeout)`; для OpenRouter — заголовки `HTTP-Referer` и `X-Title`.
- **JSON-режимы:**
  - `json_schema` → `response_format={"type":"json_schema",...}`;
  - `json_object`;
  - `prompt` — схема в тексте + извлечение первого JSON-объекта из ответа;
  - `auto` — пробует `json_schema`; на ошибку 400 или «unsupported» кэширует откат на `prompt` для этой модели.
- Повторы через tenacity: 429 и 5xx, экспоненциальная пауза, до 3 раз.
- **Учёт:** `usage` из ответа, стоимость по `LLM_PRICE_*`; если OpenRouter вернул `usage.cost` — берём её.
- `embed()` — через `EMBEDDINGS_*` или `NotImplementedError`.
- Тест на `FakeTransport` (httpx MockTransport).

## C3. Валидаторы `core/validators/` · ✅ сделано (ветка claude/core) · к 24.09, 13:00

| Модуль | Что проверяет |
|---|---|
| `math_check.py` | Безопасный вычислитель на AST: + − × · : / ( ), целые и десятичные, «×», «·», «:», «−». Сверяет с `result` и `expected_answer`. Проверяет пределы чисел по классу (таблица в `core/grade_limits.py`: 1 кл — ≤ 20/100, 2 — ≤ 100, 3 — ≤ 1000, 4 — многозначные…). Для 3 класса и темы «в пределах 100» — ≤ 100 |
| `timing.py` | Минуты по `TaskKind` × уровень × длина текста; чтение 1 мин + рефлексия 3 мин (кейс); `TimePlan`; сценарий 15/18/20 на фикстуре должен совпасть |
| `leak.py` | `expected_answer` и результаты шагов не встречаются в `student_text` / `support` в форме «= N» или «ответ N»; в `support` нет готового действия, если `kind` его проверяет |
| `uud.py` | У индикатора есть `trigger`, и он дословно (без учёта регистра) присутствует в `student_text + support`; тип задания допускает группу (`task_kinds.py`); покрытие групп при `balanced` |
| `outcomes.py` | ID есть в `knowledge.get_outcome`; тип совпадает; `page` и `section` берутся **из каталога**, а не из LLM (перезаписываем); `verified=True` |
| `level.py` | Различие уровней по опорам и самостоятельности (T09): у лёгкого есть `support` хотя бы у половины заданий; у сложного есть требование объяснить, проверить или сравнить; числа не меньше, чем у базового |
| `language.py` | pymorphy3-согласование «N предмет»; запрещённая лексика (ярлыки способностей, диагнозы) |
