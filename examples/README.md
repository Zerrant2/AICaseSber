# Примеры работы «Сократа» на реальной модели

Сгенерировано командой `python scripts/generate_examples.py` 24.09.2026 в 18:00.
- Модель: `deepseek/deepseek-v4.1-flash` через OpenRouter.
- Нормативная база: 1–9 классы, 1072 планируемых результата.
- Промпты: версия 1.1.

Файлы не правились руками.

## `math_3_all/` — главный сценарий кейса

Запрос: математика, 3 класс, тема «Умножение и деление в пределах 100 и задачи в одно-два действия», все три уровня, 4 задания.

| Файл | Что это |
|---|---|
| `Задания_….docx` | Лист для ученика: три варианта (А, Б, В) без ответов и без слов об уровне, вопросы рефлексии |
| `Методичка_….docx` | Для педагога: ответы и решения, проверенные кодом; карта каждого задания (предметный результат со страницей ФРП, наблюдаемые УУД с цитатой-основанием, типичные ошибки, вопросы, как проводить); расчёт времени; ограничения |
| `work.json` | Полная структура работы (`DiagnosticWork`) |
| `Анализ_ошибки.docx`, `analysis.json` | Анализ типичной ошибки: «дети путают периметр и площадь» → гипотезы по слоям, приёмы из библиотеки, быстрые проверки |
| `summary.json` | Модель, токены, стоимость, время |

**Итоги прогона:**
- 12 заданий: арифметика всех шагов проверена вычислителем, ответов в тексте для ученика нет, у каждого УУД есть дословная цитата-основание;
- автопроверка нашла ошибки только в лёгком варианте, модель исправила их за 2 починки; предупреждений не осталось;
- время по расчёту: 17 / 17,5 / 18,5 мин;
- вызовов модели: 6; токены: 28 723 + 37 454; стоимость: **$0.0365**; время генерации: 126 с.

В заданиях «найди ошибку» (А-3, Б-3, В-3) неверное решение вымышленного ученика показано намеренно: это условие задачи, а не утечка ответа.

**Уровни различаются опорами и самостоятельностью, а не объёмом:**
- в лёгком варианте у каждого задания есть подсказка с началом записи;
- в базовом подсказок нет;
- в сложном ученик сам составляет план, решает двумя способами и ищет ошибку в решении из двух действий.

Результат генерации меняется от запуска к запуску. Проверки кодом одинаковые при каждом запуске.
